Consider the sentence: "The trophy didn't fit in the suitcase because it was too big." What does "it" refer to? You know instantly: the trophy. Change "big" to "small" and "it" becomes the suitcase. To get this right, a system must connect words that may be far apart and decide which connections matter. In 2017, a paper from Google titled "Attention Is All You Need" introduced an architecture built around a mechanism for exactly this. Every frontier language model descends from it.

## The problem with reading one word at a time

Before 2017, the dominant approach to language was the **recurrent neural network (RNN)**. An RNN reads a sentence one token at a time, updating a fixed-size memory vector as it goes, like a person reading through a keyhole and taking notes on a single index card.

This has two problems. First, everything the network knows about the beginning of a long passage must survive being squeezed through that one card, step after step; distant information fades. Second, reading is inherently sequential: the network cannot process word 100 until it has processed word 99, which makes training slow on parallel hardware like GPUs.

Researchers first added **attention** to RNNs in 2014 and 2015, letting a translation model look back at all the input words when producing each output word. The 2017 insight was radical: drop the recurrence entirely and build the whole model from attention.

## Attention as a soft lookup

Attention lets every token look at every other token it is allowed to see, and pull in information from the relevant ones. It works like a search engine in miniature. From each token's vector, the model computes three new vectors using learned weight matrices:

- A **query**: what this token is looking for.
- A **key**: what this token offers, as a label to be matched.
- A **value**: the information this token will pass along if selected.

To update a given token, the model compares its query with every token's key using a **dot product**, which is large when they align. The scores are scaled and passed through **softmax**, producing **attention weights** that are positive and sum to one. The token's new vector is the weighted average of all the values.

<Eq>Attention(<i>Q</i>, <i>K</i>, <i>V</i>) = softmax( <span class="frac"><span><i>Q K</i><sup>T</sup></span><span>√<i>d</i></span></span> ) <i>V</i></Eq>

That single line is the most famous equation in modern AI. You already know every piece: *QK*<sup>T</sup> computes all the query-key dot products at once (a matrix multiplication), dividing by √*d* keeps the scores in a reasonable range, softmax turns them into weights, and multiplying by *V* blends the values.

## Many heads, many questions

One attention computation can only ask one kind of question. So transformers run many **attention heads** in parallel, each with its own query, key, and value weights. Different heads learn different jobs. Interpretability researchers have identified heads that attend to the previous token, heads that track syntax, and **induction heads**, which Anthropic researchers showed in 2022 implement a simple form of in-context learning: if the current token appeared earlier, look at what followed it last time and predict that again. The outputs of all heads are combined and passed on.

## The causal mask

A model generating text must not see the future: when predicting the next word, the following words do not exist yet. During training, the full text is available, so the model is prevented from cheating by a **causal mask**: each token may attend only to itself and earlier tokens. This is why, in the demo, later words are faded. It also explains a subtle point you saw there: at the word "it," a model reading left to right cannot yet know whether the sentence ends in "tired" or "wide," so the resolution happens at a later position.

## The cost of context

Attention compares every token with every other token it can see. Double the length of the input and the number of comparisons roughly quadruples. This **quadratic** cost is why long context windows are expensive, and why so much engineering has gone into efficient attention variants. Context windows grew from 2,048 tokens in GPT-3 (2020) to hundreds of thousands and, in some models, millions of tokens by 2025, through a combination of better algorithms, hardware, and memory techniques.

A longer window does not guarantee the model uses all of it well. Researchers measure whether models can find and reason over information placed anywhere in a long context, and performance often degrades for information buried in the middle.
