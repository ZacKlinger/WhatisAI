You now know every ingredient: tokens, embeddings, matrices, nonlinear layers, attention, softmax. This module assembles them into the **transformer**, the architecture underneath GPT, Claude, Gemini, Llama, and nearly every other frontier model. Once you can trace a token through it, the methods sections of most AI papers will read as variations on a structure you know.

## The shape of the machine

A frontier language model is a **decoder-only transformer**. "Decoder-only" means it generates text from left to right, with causal attention, as you saw in the previous module. Click on each part of the diagram to orient yourself, then read on.

<StaticFigure id="transformer-block" caption="A decoder-only transformer. A token enters at the bottom as an embedding, travels up the residual stream through N repeated blocks of attention and MLP, and leaves at the top as probabilities for the next token." />

Follow one token through:

1. **Embedding.** The token's ID selects a row of the embedding table: a vector of, say, 4,096 numbers. Information about the token's position is also incorporated.
2. **The residual stream.** That vector becomes the start of the token's **residual stream**, a running vector that flows upward through the whole model.
3. **Repeated blocks.** The model has dozens of identical blocks (layers), commonly 32 to 128 in large models. Each block contains two sublayers:
   - **Attention**, which reads from the residual streams of this and earlier tokens, gathers relevant information, and *adds* its result back into this token's stream.
   - **MLP** (a small two-layer neural network), which reads this token's stream alone, transforms it, and *adds* its result back.
4. **Unembedding.** At the top, the final vector is multiplied by an output matrix to produce one score (logit) per vocabulary token, and softmax converts those to next-token probabilities.

## The residual stream: a shared workspace

The most important idea for understanding transformers, and for reading interpretability research, is the residual stream. No sublayer *replaces* the token's vector. Each one reads from it and **adds** its output to it. The stream is like a shared whiteboard that every component of the model can read and write. Attention heads move information between token positions; MLPs process information within a position; everything accumulates.

This design, inherited from residual networks, keeps gradients healthy in very deep models. But it also has a profound conceptual consequence that Anthropic researchers emphasized in their 2021 "Mathematical Framework for Transformer Circuits": because everything communicates through additions to a shared vector space, the model's computation can be decomposed into contributions from individual components. That decomposability is what makes mechanistic interpretability possible at all.

<KeyIdea track="t3">The residual stream is the transformer's spine. Attention moves information between positions; MLPs transform it in place; both write their results into the same stream by addition.</KeyIdea>

## What do the MLPs do?

If attention routes information between tokens, what are the MLP sublayers for? They hold most of the model's parameters, roughly two-thirds in a standard design, and research suggests they act partly as a vast **key-value memory**: detecting patterns in the stream and writing associated information back. Studies have found specific factual associations, such as a landmark's location, stored in particular MLP layers, and have even edited those facts directly. The picture is incomplete, but a rough division of labor is useful: **attention decides where information comes from; MLPs decide what to do with it.**

## Smaller pieces that matter

**Layer normalization** rescales each vector to a standard size before each sublayer, preventing numbers from drifting and keeping training stable.

**Positional information.** Attention, by itself, has no notion of order: a bag of tokens and a sentence look the same to it. Models therefore inject position. The original transformer added fixed wave patterns to the embeddings; most modern models use **rotary position embeddings (RoPE)**, which rotate query and key vectors by an angle that depends on position, so attention scores naturally reflect relative distance.

## Where the parameters live

You can estimate a transformer's size from its shape. With a model width (residual stream size) *d*, each block has attention matrices totaling about 4*d*² parameters and an MLP of about 8*d*² parameters (two matrices that expand the vector to 4*d* and back). So each layer holds about **12*d*²** parameters.

GPT-3 had *d* = 12,288 and 96 layers: 12 × 12,288² × 96 ≈ 174 billion. Add the embedding table and you reach its 175 billion. The formula works.

## Mixture of experts

Many recent frontier models use a **mixture of experts (MoE)** design. Instead of one large MLP per layer, there are many smaller "expert" MLPs, and a small router sends each token to just a few of them. A model might have hundreds of billions of total parameters while using only a fraction for any given token. This decouples **total parameters** (knowledge capacity) from **active parameters** (compute per token). When you read "a 671B-parameter MoE with 37B active," as in DeepSeek's V3 model, the second number determines inference cost and the first, roughly, capacity.

## What hasn't changed since 2017

It is striking how little the core architecture has changed. Frontier models of 2026 still use the 2017 skeleton: embeddings, a residual stream, attention, MLPs, normalization, and unembedding. The refinements are real (rotary positions, better normalization placement, gated activations, mixture of experts, efficient attention), but the dominant source of progress has been scaling the same design up, training it on better data, and post-training it more skillfully. That is the bitter lesson in action.
