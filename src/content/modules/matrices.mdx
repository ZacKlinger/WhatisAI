If vectors are the nouns of AI, matrices are the verbs. A matrix takes a vector and transforms it into another vector: rotating it, stretching it, mixing its entries, or projecting it into a space with a different number of dimensions. Nearly all the computation inside a neural network is matrix multiplication. Understanding it demystifies what a network "does" to its inputs, and explains why AI became a story about chips.

## A grid of numbers

A **matrix** is a rectangular grid of numbers. This one has two rows and two columns:

<Eq>[ 2 &nbsp; 0 ]<br/>[ 1 &nbsp; 3 ]</Eq>

On its own, that is just a table. The power comes from what it does to vectors.

## Multiplying a matrix by a vector

To multiply a matrix by a vector, take the dot product of each **row** of the matrix with the vector. Each row produces one number of the output.

<Eq>[ 2 &nbsp; 0 ] · (4, 5) = 2×4 + 0×5 = 8<br/>[ 1 &nbsp; 3 ] · (4, 5) = 1×4 + 3×5 = 19<br/><br/>so the matrix sends (4, 5) to (8, 19)</Eq>

Notice what this means. Each output number is a weighted sum of all the input numbers, and the weights are the entries in that row. A matrix is a bundle of weighted sums, computed all at once. That is exactly what a layer of a neural network computes: each output neuron takes a weighted sum of all the input neurons, and the weights live in a matrix.

## A matrix is a transformation of space

There is a second, more visual way to see a matrix. Apply it to *every* point in space at once, and space itself moves. A 2×2 matrix tells you exactly where the two basic arrows go: the first column is where the arrow (1, 0) lands, and the second column is where (0, 1) lands. Everything else follows, because a matrix transformation keeps grid lines straight, parallel, and evenly spaced.

Some transformations you can make:

- **Rotation** turns space without stretching it.
- **Scaling** stretches or shrinks along the axes.
- **Shear** slants space, like pushing the top of a deck of cards.
- **Collapse** squashes the whole plane onto a line. The determinant becomes zero, and different input points now land on the same output point. Information has been destroyed; you cannot undo it.

<KeyIdea track="t1">A matrix is a recipe for weighted sums, and equivalently a transformation of space. A neural network layer is a learned transformation: it moves the data into a new arrangement where the next step is easier.</KeyIdea>

## Changing dimensions

Matrices need not be square. A matrix with 3 rows and 2 columns takes 2-dimensional vectors and produces 3-dimensional ones. A matrix with 1,000 rows and 4,096 columns takes a 4,096-dimensional vector to a 1,000-dimensional one.

This is how models move between spaces. The final layer of a language model is a matrix that takes the model's internal vector (a few thousand numbers) and produces one score for every token in its vocabulary (often around 100,000 numbers). The first layer of a transformer works the other way, through an embedding table: each token looks up its own row, a vector of a few thousand numbers.

## Counting parameters

A weight matrix with *m* rows and *n* columns contains *m* × *n* parameters. This simple fact explains where the billions come from.

A single 4,096 × 4,096 matrix holds 4,096 × 4,096 ≈ **16.8 million** parameters. A transformer layer contains several such matrices, and a large model stacks dozens of layers. Multiply it out and you reach tens or hundreds of billions.

## Matrix times matrix

You can also multiply two matrices. The result is a single matrix that performs both transformations in sequence: first one, then the other. This has a surprising consequence. If a network were made only of matrix multiplications, stacking a hundred layers would be no more powerful than one layer, because a hundred transformations composed together are still a single linear transformation. Something non-linear must be inserted between the layers to give depth its power. You will see what that is in the neural networks module.

## Why AI runs on GPUs

Multiplying two large matrices requires an enormous number of small multiplications and additions, but almost all of them are independent of each other, so they can be done at the same time. Graphics processing units (GPUs) were designed to compute millions of pixel colors in parallel for video games, which turns out to be the same kind of work.

That coincidence shaped history. The AlexNet breakthrough of 2012 was trained on two gaming GPUs. Today NVIDIA's data-center chips, Google's TPUs (Tensor Processing Units), and other accelerators are specialized almost entirely for matrix multiplication, and access to them is a strategic asset that governments now regulate. When you read about export controls on AI chips in Track VIII, remember that the thing being controlled is, at bottom, an extraordinarily fast way to multiply matrices.
